# PUCHI CHAIN

「コアループの完結」と「引き算のゲーム設計」から生まれた、プチプチの空気押し出し×連鎖破裂のミニマルなブラウザゲームです。

公開ページ: https://kawata2271.github.io/puchi-chain/

## コンセプト

プレイヤーは時間とともに膨らむ泡をクリックで潰して、赤く限界を超えて自爆するのを避けながら、隣り合うパンパンの泡を連鎖破裂させてハイスコアを目指します。操作はクリック（またはタップ）による「潰す」というひとつの動詞だけです。

まだ小さい泡を潰すと中の空気が上下左右にある生きている泡へ押し出され、隣の泡を意図的にパンパンへ育てて連鎖の橋を架けることができます。すでに潰れて空になったマスや盤面の端には空気が逃げないため、逃げ場を減らして一方向へ空気を集中させることも可能ですが、押し込みすぎると隣が赤く危険状態になったりその場で自爆したりするリスクも伴います。白く張り詰めた臨界状態の泡を潰すと、繋がっている臨界泡や危険泡が小気味よいリズムと上昇する音階で次々とドミノ破裂し、四連鎖以上で盤面上の他の危険泡の猶予時間もわずかに押し戻されます。

## 特徴

外部ライブラリや画像・音声素材を使わず、HTML5 Canvas と Web Audio API のみで構成しているため、ビルド不要でそのまま動作します。画面右上には「プロトタイプ」ボタンと「調整」ボタンを備えており、音や色やエフェクトをすべてオフにした灰色の四角と丸だけでコアループを検証したり、膨張スピードや空気の押し出し量、臨界ライン、自爆猶予時間、連鎖間隔を遊びながらリアルタイムに変更したりできます。

## ローカルでの起動方法

リポジトリ内の `index.html` をそのままブラウザで開くか、任意の静的サーバーで配信して遊べます。

```bash
python3 -m http.server 8765
```
