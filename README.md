# PUCHI CHAIN

「コアループの完結」と「引き算のゲーム設計」から生まれた、升目なし2D物理クラスタ×縦スクロール掘削のプチプチ連鎖アクションパズルです。

公開ページ: https://kawata2271.github.io/puchi-chain/

## コンセプト

プレイヤーは物理演算でぎゅうぎゅうに詰まった泡を潰して連鎖爆発で空間をぶち抜き、上から迫る赤いプレス天井と赤泡の自爆を避けながら、重力で落ちる光るコアとともに深い地層へ潜り続けます。操作は「泡を潰す」というひとつの動詞だけです。

通常の泡は待っているだけではほとんど膨らまないため、自分で小さい泡を押して離すことで物理的に接触している周囲の泡へ空気を追い込み、パンパンの臨界塊を作り出す必要があります（押しているあいだはラバーバンドのように凹んで空気の移動先と危険予兆が表示され、指を離すと確定、大きくずらすとキャンセルできます）。白く光る臨界泡や赤い危険泡に触れると即座に連鎖爆発が走り、爆風で周囲の泡が吹っ飛んで雪崩のように崩れ落ち、光るコアが下の空洞へ一気に落下してカメラが深くスクロールします。

深さに応じて表層・翡翠の峡谷・琥珀の岩盤・深紫の鍾乳洞・深淵マグマへと画面の色と地形が移り変わり、うねる狭い壁や丸い岩柱、直接タップでは割れず隣の連鎖爆風で砕く「硬い殻の泡」が立ちはだかります。

## 特徴

外部ライブラリや画像・音声素材を使わず、HTML5 Canvas と Web Audio API のみで動作します。画面右上から「プロトタイプ」モード（灰色の丸と線だけの検証モード）や「調整」パネル（プレス速度・空気押し出し量・臨界ライン・赤泡猶予・連鎖間隔）をいつでも切り替えられます。

## ローカルでの起動方法

リポジトリ内の `index.html` をそのままブラウザで開くか、任意の静的サーバーで配信して遊べます。

```bash
python3 -m http.server 8765
```
