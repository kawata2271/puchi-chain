# PUCHI CHAIN

「コアループの完結」と「引き算のゲーム設計」から生まれた、プチプチの空気押し出し×連鎖破裂のミニマルなブラウザゲームです。

公開ページ: https://kawata2271.github.io/puchi-chain/

## コンセプト

プレイヤーは時間とともに膨らむ泡を潰して、赤く限界を超えて自爆するのを避けながら、色つきの未破マスをすべて連鎖で破って次々と新しい形のプチプチシートへ進むゲームです。操作は「潰す」というひとつの動詞だけです。

まだ小さい泡を押しているあいだは泡がぐっと凹んで空気の移動先と状態変化の予兆が表示され、そのまま指を離すと中の空気が上下左右にある生きている泡へ押し出されます（別のマスへ指をずらすとラバーバンドのように戻ってキャンセルできます）。穴や盤面の端、潰れて空になったマスには空気が逃げないため、ドーナツ型や二つの島、S字回廊などの地形を活かして逃げ場を絞り、狙った泡へ空気を集中させて連鎖の橋を架けるパズル的な面白さが生まれます。

シート上の色つきマスをすべて連鎖破裂で破ると、残りの泡が波紋のように一斉に弾け飛び、新しいカラーテーマと新しい形のシートへ丸く広がって切り替わります。

## 特徴

外部ライブラリや画像・音声素材を使わず、HTML5 Canvas と Web Audio API のみで構成しているため、ビルド不要でそのまま動作します。画面右上には「プロトタイプ」ボタンと「調整」ボタンを備えており、音や色やエフェクトをすべてオフにした灰色の四角と丸だけでコアループを検証したり、膨張スピードや空気の押し出し量、臨界ライン、自爆猶予時間、連鎖間隔を遊びながらリアルタイムに変更したりできます。

## ローカルでの起動方法

リポジトリ内の `index.html` をそのままブラウザで開くか、任意の静的サーバーで配信して遊べます。

```bash
python3 -m http.server 8765
```
